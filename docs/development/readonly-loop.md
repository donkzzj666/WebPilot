# 第一个公开只读闭环（M1-25）

本项在已登记的 C1-01 调试输入上收窄为一个固定 arXiv 版本页面的元数据读取。它验证 UI → 自然语言编译 → 冻结契约 → 持久队列 → 默认 Worker／LangGraph → 受管浏览器 → 原文解析／独立语义核验 → 成功聚合 → 结果与受控证据展示。不执行论文搜索、附件读取、主张提取或关系分析；不声明整张 C1-01 或正式评测通过。

## 原文核验

`verification/arxiv.py` 只解析 `https://arxiv.org/abs/<明确论文 ID>v<明确版本>` 页面。原始 `{title,text,text_truncated}` 浏览器工件必须明确声明采样未截断，包含唯一的 Title／Authors 标识、相符的 arXiv ID／版本和可解析的 UTC submission history。缺失、截断、日期歧义、版本缺失或地址不符均不提供可通过的字段。采样是否截断由网关的固定 DOM 探针判定并保存在原件中，不能由模型声明。解析发生在验证服务读取并核对原件哈希之后，不读取模型建议值，也不把展示副本当作原件。该适配器只支持当前严格标记和作者格式，其他布局保持不足；不声明通用 arXiv 页面解析完成。

`first_published_at` 来自 `[v1]` 提交记录；`revised_at` 对 v1 为 null，对后续版本来自该指定版本的提交记录。v1 的指定版本提交时间就是首次提交时间。空的 `claims`／`relations` 表示本次不提取这些信息，不能解释成论文没有主张或关系。

固定版本查询为 `arxiv:<ID>vN`，只允许一个目标和 `max_items=1`。已读取来源、页面数和完成范围从本 Run 的真实观察、已完成动作与内容页预算扣额共同核对；cutoff 是明确标注来源的冻结请求边界。额外导航、范围外观察、失败／未知动作或不一致扣额会阻止通过。coverage 完整仅指这个已指定页面，不能解释成全网召回完整。

纯规则对每个输出字段绑定原始证据，独立语义模型只收到冻结要求、候选事实和原始证据小胶囊；最终结果仍由本地聚合器决定。通用 JSON 原件路径继续保留。

固定页面的路径范围仍限制全部请求。未声明来源的样式、图片、字体、媒体和脚本继续阻断；只有来自当前受管主文档、资格有效、明确非导航和非重定向的 GET／HEAD 资源阻断可作为可选失败处理。文档、子 frame、数据请求、写请求、重定向、未知类型、缺租约或原生防护故障均保持关键失败。页面可能因此呈现无样式正文，原文采样仍以实际可见 DOM 为准。

## 可重复运行

先通过产品设置保存真实 DeepSeek 配置到一个新的隔离数据目录；密钥保存在系统凭据库。该目录必须已迁移且没有任务或 Run。真实验收是显式入口，可能产生供应商费用；常规 `check.sh` 不调用真实供应商。

运行前必须实际确认系统 DNS 和产品 `NetworkPolicy.resolve` 返回公网地址。若 VPN 的 Fake-IP 模式返回 `198.18.0.0/15` 等非公网地址，产品会拒绝 `unsafe_address`；普通浏览器能打开页面不能替代这项检查。Shadowrocket 的“总是真实 IP”域名列表可明确保留主域名 `arxiv.org` 和 `*.arxiv.org`，保存并应用配置后重新验证。本轮在向用户建议补充主域名之后，实际复查确认系统及产品解析器恢复了公网解析；仅靠配置截图不宣称生效。以实际查询结果为准，不硬编码站点 IP，也不修改产品地址拒绝规则。

```sh
.venv/bin/python scripts/verification/verify_readonly_loop.py \
  --data-dir /绝对路径/本次隔离数据目录 \
  --output /绝对路径/全新验收输出目录 \
  --headed
```

探针使用正常三端启动入口和默认执行依赖，不注入模型回答、站点镜像、READY 契约或成功账本。任务创建、缺参补充（若需要）与启动都通过真实 UI。macOS 运行进程用系统读隔离 profile 禁止访问 M0 准备资料、完整登记、答案目录、Git 历史及旧验收工件；启动前验证真实拒读，同时确认运行源码可读。浏览器继续经过产品本身的 public 网络边界。

真实流程失败会保留首个错误、受理已启动任务的取消清理并停止自有进程，不自动重跑或改写账本。原件、业务库、凭据引用和原始日志留在私有目录；公开报告保留安全汇总、结果截图、证据元数据及哈希。自动报告通过仍不等于已完成要求中的人类原页面对照。
