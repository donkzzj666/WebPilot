# 执行工作台与实时进度

任务入口保存契约后，在“执行进度”核对该任务的契约、来源和允许动作，并明确确认启动。启动、暂停、继续和取消复用既有运行控制 API；创建任务和选择任务不会自动启动。配置就绪只表示本机可以读取配置及凭据，不证明提供商可用。

## 状态和控制回执

工作台以同一 SQLite 读快照展示当前 Run 状态与版本、冻结的契约／设置版本、实际子目标、检查点、剩余预算、队列原因、最近图阶段和持久业务事件。子目标来自检查点，不将模型文字或内部推理当作进度；验收项的已验证标记也来自持久记录。

HTTP 202 只表示操作已受理。界面保留 operation ID，显示处理中，查询持久回执，并重新读取工作台。只有 APPLIED 或 REJECTED 回执才能说明操作处理结果；运行状态仍以最新 API 快照为准。暂停要等待 Worker 的安全边界，取消也不会回滚已派发的外部动作。

启动提交任务版本及当前设置版本。暂停、继续、取消提交 Run 版本和该 Run 冻结的契约／设置版本，即使全局配置已变化也不能改用新版本。未完成操作、过期连接、未知响应、版本冲突或未确认目标时禁用新的控制。恢复不绕过预算、人工接管、UNKNOWN 或服务端状态机。

可信内部测试或旧记录可能没有配置快照，读取接口以设置版本 0 明确表示缺失；界面禁止控制这些 Run。公开 ControlStore 启动的 Run 必须具有真正的正版本配置快照。

请求结果未知时，界面保留当前组件内的原请求正文与幂等键，先查询；同一请求的重试沿用原键。页面重载后只重新读取持久对象，不恢复未提交的授权，不自动重发控制。不要将不确定结果视为失败后重新提交另一操作。

## 实时事件与恢复

浏览器通过 `apiFetch` 读取 SSE 流，以便附带本机客户端标记和 `Last-Event-ID`。它不使用无法设置这些头的 EventSource。帧和响应都有大小上限、目标绑定和格式校验；事件 ID 保留为十进制字符串，避免 SQLite 64 位整数经过 JavaScript Number 后失真。

事件用于触发权威快照读取，不直接乐观修改 Run。相同 ID、相同内容只处理一次；相同 ID 内容变化或新到达的较小 ID 触发重同步。事件 ID 是全库序列，过滤后的正常间隙不能视为丢失事件。断线、异常帧或心跳超时将界面标为过期并锁住控制，随后有界重连，读取 JSON 重放页和新快照恢复；任务切换与组件卸载会中止旧订阅。

图阶段可能在没有新业务事件时更新，因此还会定时读取工作台。持久业务事件、图诊断、连接健康和任务成功是不同信息，连接正常不能表示运行已完成。

## 页面证据

页面面板显示最新受管观察的快照标识、时间、有效性及关联证据。失效快照有明确标记。工作台 API 不返回私有路径、原页面 DOM、模型提示或未过滤 URL。

内容只通过 `/v1/evidence/{evidence_id}` 和 `/content` 认证读取，沿用完整性、可用性及脱敏检查。图片使用认证请求获取的 blob 与临时 object URL，文本以纯文本展示；离开时撤销 URL，不执行 HTML，不嵌入原站点。当前截图策略可能返回隐私保护的中性 PNG，不能将其称为完整原始截图。证据不可读时显示原因，不能将缺证据显示为成功。

## 只读投影接口

| 接口 | 返回与边界 |
| --- | --- |
| `GET /v1/tasks/{task_id}/workspace` | 当前任务／Run、冻结条件、最新检查点、20 条图阶段、20 条控制、100 条业务事件、预算、队列与页面证据 |
| `GET /v1/tasks/{task_id}/workspace?run_id=...` | 只读指定历史 Run，必须属于该任务；当前 UI 只操作当前 Run |
| `GET /v1/runs/{run_id}/events?after=0&limit=100` | 按全局 ID 升序返回该 Run 的事件，十进制字符串 cursor／high_water，最多 100 条 |

每次投影使用 `mode=ro`、`query_only`、短等待、有界 SQLite 工作量和一次读事务；不建库、迁移、预算结算、恢复、调用模型或领取队列。缺库／结构未就绪／读故障返回安全 503；非法、重复或未知查询参数拒绝。接口要求本机鉴权，响应不可缓存。

## 代码与验证

| 位置 | 职责 |
| --- | --- |
| `backend/webagent/workspace/` | 一致只读投影、ID 绑定和事件分页 |
| `frontend/src/workbench/` | 工作台、控制收据、流解析、去重与重同步、证据读取 |

```sh
./scripts/check.sh
.venv/bin/python scripts/verification/verify_workbench.py \
  --output-dir "/tmp/webpilot-workbench-$(date -u +%Y%m%dT%H%M%SZ)"
```

探针仅使用自己的合成站点、模型 HTTP、内存测试凭据和独立存储，不启动或迁移默认业务库。重复／乱序／断线通过传输故障注入验证；READY 准备与站点门控是明确标注的夹具，动作预算耗尽由实际导航和动作拒绝验证。它们不能替代实际外部业务、真实账号或 M1-25 的公开只读闭环。最终范围和失败历史见 [M1-21 验收记录](../m1/records/M1-21.md)。
