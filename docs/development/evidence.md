# 证据工件、脱敏与受控读取

M1-14 将网关得到的页面样本和动作工件接入独立证据域。业务 SQLite 保存归属、哈希、采集范围、观察／步骤绑定、过滤版本和可用状态；文件保存在本机 `data/evidence/`。本项已通过验收，证据见[M1-14 记录](../m1/records/M1-14.md)。

`FILTERED` 不能只由调用者填写。模型调用必须使用已登记的脱敏观察，逐项匹配 Run、快照、来源、标签、帧、页面版本和尺寸；真正发送前重新读取引用工件并核对实际字节、长度、SHA-256、过滤策略及观察绑定。修改内存里的标题、正文、证据 ID 或图片状态不能替代此登记。

## 模块与调用顺序

| 模块 | 责任 |
| --- | --- |
| `models.py` | 有界元数据、允许工件类型和 MIME |
| `files.py` | 私有文件、目录锚点、排他发布锁、校验与不可覆盖重命名 |
| `store.py` | 显式索引提交、可用状态、保留策略、孤儿登记及存储故障门 |
| `redaction.py` | 确定性文本过滤、冻结语义阻断及全灰 PNG 字节证明 |
| `service.py` | 网关观察／动作工件、模型输入资格及展示副本 |
| `routes.py` | 本机认证后的证据 ID 查询与内容读取 |

受信 Worker 通过 `EvidenceService.publish_observation()` 保存观察；原件和文本展示副本分别发布，然后登记不可变的 `filtered_observations`。结构化动作网关在保存结果时发布步骤工件和回执，发布失败不会把未保存的结果提供为完成结果。`ModelAdapter.generate()` 在调用前及格式修复的每一次实际请求前核对证据；底层模型传输和自然语言编译也重新过滤文本。没有公开上传接口，也没有由模型指定文件路径的入口。

内部的 `EvidenceStore.publish(run_id, data, ...)` 接受有界字节与元数据。已调度 Run 必须提供当前执行 Token，提交前重查资格。CI 工件还须绑定 commit SHA 和 test run ID；展示副本必须引用同一 Run 的原件，并登记过滤策略。

## 保存协议与不可变历史

schema v13 追加 `evidence_artifacts`、`evidence_availability`、`evidence_retention`、`evidence_events`、`filtered_observations`、`evidence_orphans` 和故障／Run 保护表，沿用原有 `evidence` 及观察／步骤关联。v1～v12 SQL 不重写。发布事实与可变的可用状态分开，触发器保护已发布元数据、哈希和脱敏观察的历史。

文件由程序生成随机名称，目录权限为 `0700`，文件为 `0600`。路径遍历采用不跟随符号链接的目录描述符，读取还检查文件所有者、权限、硬链接数量及前后文件身份，避免文件或父目录被替换。单个工件最多 64 MiB；不使用网页给出的文件名作为本机路径。

一次发布按顺序执行：

1. 独占发布锁，检查存储故障门和当前 Run 资格。
2. 创建不可覆盖的临时文件，写入全部字节、`fsync`，重读并验证长度及 SHA-256。
3. 使用平台的原子且不覆盖目标的重命名，刷写目录。
4. SQLite 短事务重新核对资格，提交证据索引、观察／步骤关联、保留策略及审计事件。

文件和 SQLite 不能组成一个跨介质事务。半写中断可能留下 `.tmp`；重命名后索引失败可能留下 `.blob`。它们没有正式证据 ID，不能被模型或 HTTP 读取。`scan_orphans(grace_seconds=3600, cleanup=False)` 在同一发布锁下登记未索引候选；显式使用 `cleanup=True` 时再次核对数据库和文件身份后清理，避免删除另一进程正在提交的工件。清理默认有宽限期，不能把刚写出的文件当孤儿。

重复证据 ID 被拒绝；修订内容必须创建新 ID，并保留原件／副本对应关系。副本和原件各有独立哈希，副本哈希不能证明原始信息完整。

## 文本与图片的模型边界

文本过滤固定使用 `[REDACTED]`，重复过滤保持稳定。规则覆盖已知字面密钥、常见模型／GitHub／AWS 凭据、Bearer、Cookie／Set-Cookie、私钥 PEM、密码／密钥／令牌／OTP 的带标签值及 URL 身份信息和敏感参数。检测使用 Unicode 兼容归一化并排除零宽字符；没有敏感内容的事实、数字、ID 和普通文本保持原样。文本、嵌套深度、节点数及 UTF-8 字节总量有界，错误不包含原始内容。

观察标题和可见正文可替换敏感值；契约、检查点、ID、来源 URL 等绑定值若含敏感信息，会在供应商调用前返回 `INPUT_BLOCKED`，不会改成另一个地址或语义。自然语言编译同样只过滤 `instruction` 与 `web_context` 自由文本，显式参数和场景中的敏感绑定被拒绝。展示 URL 会移除 userinfo、敏感查询和 fragment，因此不能拿展示 URL 重新授予访问权限。

确定性文本规则不代表能识别所有未知秘密，受信调用者可以传入 `known_secrets` 补充已知字面值。原件持续限制在本机核验边界内；不能把数据库中的 `FILTERED` 标签作为绕过实际字节检查的依据。

原始截图、扫描 PDF、图像、HAR 等不透明内容默认 `BLOCKED`。DOM 文本为空也不能证明 canvas、CSS 背景或嵌入图片里没有凭据；本项没有 OCR 或自动局部遮罩的许可判断。

受信调用者可显式要求 `mask_screenshot=True` 生成全灰 PNG。它保留尺寸，删除全部原始像素及附加元数据；模型边界独立验证 PNG 结构、CRC、有界解压和每个像素的固定颜色后才允许发送。这类副本没有视觉上下文，不能用于坐标定位、视觉业务证明或证明页面实际显示了什么。网关的坐标动作仍绑定其内部受限原始截图、当前页面及严格像素哈希；全灰展示副本不能替换该绑定。

## 受控读取

接口沿用 M1-12 的本机 Bearer、精确 Host／Origin 和前端代理鉴权：

| 接口 | 返回 |
| --- | --- |
| `GET /v1/evidence/{evidence_id}` | 已校验展示副本的元数据，不含本机路径 |
| `GET /v1/evidence/{evidence_id}/content` | 已校验文本／diff 或全灰 PNG 副本 |

读取只接受字母、数字、下划线和短横线组成的有界 ID。路径、`../`、查询参数、任意本机文件、原件导出及公开发布均不受支持；没有认证会在业务接口之前被拒绝。前端可以通过现有 `apiFetch('/api/v1/evidence/' + id)` 使用受限代理；结果页面将在 M1-22 接入。

每次读取重新核验工件存在性、文件安全、长度和哈希。缺失／损坏返回 `409`，过期返回 `410`，受限原件或没有批准展示格式返回 `403`；不会拿元数据摘要代替缺失的正文。响应使用 `Cache-Control: no-store`，展示元数据还会重新过滤。普通读取不获得 `allow_restricted=True` 的内部原件核验许可。

## 保留、故障与成功前提

普通工件默认自发布起保留 30 天。到期检查或 `expire_due()` 先将可用状态标为 `EXPIRED` 并保留审计记录，此后读取及模型发送拒绝；不会先删文件再伪装可用。当前入口不自动删除已索引工件。正式验收、评测或需长期复核的证据必须由受信调用者使用 `retain=True`，保持至显式清理；生命周期策略登记后不可原地改写。

文件系统 `ENOSPC`／`EDQUOT` 和 SQLite `FULL` 会锁存持久存储故障。控制标记在首次发布前预分配并刷写；磁盘满时采用在位更新或失效标记，使新进程也能识别故障，不能因重启而恢复为正常。故障门同时阻止新增浏览器派发和供应商请求。恢复需显式人工维护与验证，本项没有自动清除故障或公开恢复按钮。

已接入证据域、网关或持久调度的 Run 在转入 `SUCCEEDED` 前检查引用工件；缺失、损坏、过期或不完整的索引不能被当作成功。此项提供工件完整性的必要门槛，全部关键业务条件、独立语义核验和成功／部分／失败聚合由 M1-15 实现。

默认 Worker 保持 `task_execution_enabled=false`，产品 LangGraph 循环由 M1-16 接入。本项不声称正式网站写入、完整运行恢复、结果页或真实业务闭环已经完成；不通过测试成功自动启动旧服务或迁移用户现有数据。
