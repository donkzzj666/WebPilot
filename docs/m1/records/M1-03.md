## 交付

- 追加业务迁移 `0003_state_events.sql`，保留 v1／v2 已应用迁移；最新数据库版本为 3。
- 12 个 Run 状态、33 条合法转移。数据库与服务共用转移表，非法／自循环转移被拒绝，终态不可原地恢复。
- 乐观版本比较；状态、版本递增、状态事件在同一事务提交。事件插入失败、提交失败、提交前进程中断均回滚；提交后中断保留两者。
- 结构化动作／等待／结果事件追加，事件 ID 在全库递增，事件只追加，读取仅见已提交记录。
- `GET /v1/events` 支持 `Last-Event-ID`、任务／运行过滤、分页重放、实时跟随、无 ID 心跳和断线释放。API 重启后继续从 SQLite 重放。
- 共用错误适配器：版本冲突 409、参数错误 422、不存在 404、忙锁 503。生产 API 仅新增 SSE；409 通过测试专用路由调用真实服务及共用适配器验证，任意设置状态的接口未对外开放。

使用方法、状态转移表、SSE 帧和边界见[状态与事件开发说明](../../development/state-events.md)。
