## 交付

- 受保护的登录创建、查询、确认、关闭、站点列表与身份列表 API。独立 Worker 经私有认证 Unix socket 接收元数据请求并持有浏览器，API 不创建另一个管理器；Worker 停止返回 503。
- 默认 GitHub 固定站点适配器，明确预期账号；新鲜导航、固定身份信号、账号精确比较、CDP 隔离环境与导航变化检测，拒绝未登录、错账号和不确定信号。
- schema v9 追加登录请求、身份、不可变核验和登录事件。候选引用不属于已建立身份；两次页面核验与生产 AES 保存后才在一个 SQLite 事务中发布账号、认证元数据和状态。
- 版本比较处理过期／并发确认；显式关闭、窗口丢失、Worker 重启和过期认证恢复均保守处理。恢复身份始终保留身份及业务重查要求，不把旧快照当成当前身份确认。
- 登录上下文永久禁止普通模型采集入口和通用认证导出；API 拒收凭据、选择器、脚本和任意 URL，不采集截图、全 DOM 或输入值。敏感认证 JSON 仅由会话模块加密处理。
- M1-12 令牌首次初始化增加排他锁文件创建，修复本次全新安装验收复现的 macOS 并发创建失败。保留私有权限、禁止符号链接和跨进程锁检查；依赖锁没有变化。

接口、手动验证步骤、模块导读和支持范围见[登录与身份说明](../../development/identities.md)。首次登录新增必填 `expected_account`；返回保留冻结接口 `login_session_id`／`context_id`，同时提供内部名称别名。201／200 必须结合业务 `state` 判断，只有 VERIFIED 才返回本次有效的 `identity_ref`。

## 适用边界

真实浏览器矩阵使用本机合成站点，既不使用用户凭据，也不需要 GitHub 登录。生产适配器已按官方公开页面／脚本的身份信号实现，真实 GitHub 账号登录仍待用户手动验证，不能把合成矩阵当成真实账号已通过。生产 AES 在此使用内存测试密钥，原生 Keychain 由同次独立认证探针覆盖。

失败的外部加密写入可能留下未发布密文；没有身份引用或恢复权限，当前不自动回收。列表中的历史身份不是当前会话授权；之后的 Run 仍须重新验证身份和业务条件。

本项交付 API 与 Worker 登录准备，账号展示界面留在 M1-20，任务调度和执行仍未开放。本次没有重启用户旧服务、迁移用户原有业务库、提交或推送 Git；新功能需重启 API／Worker 后使用。
