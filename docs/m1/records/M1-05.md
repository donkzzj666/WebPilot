## 交付

- 四种严格输出：Action、RequestEvidence、ProposeResult、RequestInput。覆盖十种允许动作与各场景结果；拒绝任意代码工具、未知字段、重复 JSON 键、非有限数和直接成功声明。
- DeepSeek 异步 HTTP 传输，支持 JSON 模式及明确选中的内联图像；限制地址、重定向、响应大小和图片大小。密钥显式注入，不读取现有真实凭据。
- 按契约最多修复 0／1／2 次；格式修复共用整轮期限和原 Run 的计量。模型限流、认证失败、传输错误及超时不自动重试，不映射为网站反爬。
- 显式 v5 迁移追加调用组与尝试账本。网络请求前预记账，结束时保存安全元数据；未知用量为 null。每次尝试累加原 Run 的调用次数和活动耗时，不持有跨网络事务。
- 输入绑定已持久化的契约、模型配置和预算；同 Run 并发请求被阻止，运行状态变化时丢弃过期候选。异步取消关闭 HTTP 响应并保留记录。
