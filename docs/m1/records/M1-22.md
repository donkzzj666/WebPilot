# M1-22：结果与证据页面

状态：**VERIFIED**。2026-10-02（北京时间）。最终 v4 代码、实际界面、全新安装回归及数据保护核验全部通过。M1 已完成 **23/25**；M1-24／25 保持 TODO。

本项沿用 schema v18、现有依赖和受控证据读取协议，无新增迁移。选择任务后可在「结果与证据」查看当前结果、打开对应证据和切换历史运行。接口、目录和使用方式见[结果页说明](../../development/results.md)。

## 交付

| 能力 | 行为 |
| --- | --- |
| 实际字段值 | 根据持久字段路径展示结果值，区分缺失与 `null`；验证器诊断单独折叠保留 |
| 四种检查结论 | PASS、FAIL、INSUFFICIENT、CONFLICT 均展示说明和对应证据，检查不冒充业务值 |
| 覆盖与人工参与 | 展示来源、检索条件、截止时间、未读候选、覆盖缺口、未决项及人工参与次数 |
| 独立运行历史 | 保留失败、取消和重跑关系；`result_run` 支持刷新后恢复所选历史运行，保留其他页面参数 |
| 业务结果与当前证据 | 历史聚合结论不可改写；证据丢失、损坏、过期、无安全副本或未决写入会阻止当前完整成功展示 |
| 受控证据 | 只读取绑定所选运行的过滤文本、差异或中性 PNG；浏览器再核对派生关系、来源、快照、长度、MIME 与 SHA-256 |
| 副作用 | 同时展示历史聚合记录和任务范围的当前写入意图；UNKNOWN／INTENT 不被重跑成功隐藏，失败或取消不表示回滚 |
| 读取故障 | 刷新、证据读取或历史分页发现问题时撤销旧成功提示；权限依据缺失时说明不可核查，不凭空认定违规 |

新增 `GET /v1/tasks/{task_id}/results`，支持 `run_id`、`before` 和 `limit`。查询使用一次有界只读事务，核验结果／验证记录哈希、冻结契约和任务／Run 绑定；历史游标保留十进制字符串。投影不建库、迁移、写可用性事件、结算预算或启动执行，文件控制标记也只读打开。接口沿用本机认证、Origin 防护及 no-store。

结果探针在独立数据域中创建 14 个任务、36 次运行，其中 13 份结果由真实 `VerificationService.verify/finalize` 聚合。证据字节来自自有 HTTP 服务，四种字段结论由原文匹配、错误值、缺失证据和冲突证据实际产生；没有直接插入成功结果或伪造页面响应。

运行准备、契约、人工次数、21 次用于分页的旧终态运行、重跑关联和 1 条 UNKNOWN 写入是明确标注的受约束账本夹具。刷新 503 是单独标记的传输故障注入；证据读取失败则在元数据成功返回后真实损坏自有副本，内容接口返回错误。分页用例真实损坏工件，再调用真实历史查询，验证同一 Run 版本下的新证据状态也会撤销旧成功。

每轮验收覆盖成功、部分、失败、取消、无结果、人工协助、损坏／被阻止的证据、历史失败后重跑成功，以及真实字段值、认证和跨任务拒绝。六类合成敏感标记的公开工件扫描通过；私有原文留在 `.private`，不复制到公开验收包。模型提供商调用、真实外站请求和物理仓库写入均为 0。中性 PNG 不代表原网页视觉内容；本次实际页面证据读取为过滤文本，PNG／diff 分支通过协议和客户端测试覆盖。此项不替代 M1-25 的公开只读闭环。

默认 API／Worker／前端没有因本次验收重启，默认两库没有迁移。三份既有活动日志完整哈希及基线前缀一致，六个 SQLite／WAL／SHM 路径在不可变只读核验前后保持不变；历史 M1-17／18／19／20／21／23 的保护资料保留原件。
