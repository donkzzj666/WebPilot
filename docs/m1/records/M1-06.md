## 交付

- `POST /v1/tasks`／`revisions` 支持显式 `compiler_mode=natural_language`，旧 fixture 模式和历史幂等摘要兼容。
- 独立编译提示与严格输出 Schema，模型只提出场景、业务参数和歧义字段；程序从用户字面或受控枚举映射核对依据，再生成完整任务契约。
- 明确单对象、固定期间的只读任务进入 READY；缺对象、时期、授权、身份或 Grafana 时间窗口进入 NEEDS_INPUT，响应提供补充问题和字段来源。
- 补充只允许当前请求字段，不再调用模型；草稿、契约、原始指令与授权来源均保留版本历史。非终态 Run 阻止变更，正在进行或结果未知的编译也阻止内部入口启动旧目标。
- 网页背景、显式网页段落、引用和代码块不参与关键参数依据判断；默认只读，写权限／来源／账号／预算由程序和显式 API 声明控制。
- v7 显式迁移新增独立的准备调用记录；一次预留、事务外模型等待、任务版本与成功回执原子提交。失败回执也持久化，STARTED 未知结果阻止盲重试，调用没有伪造 Run。
- 模型调用入口检查本机 Host／Origin；使用固定设置快照、一次模型尝试、最多 60 秒总时限，记录安全用量和错误，不保存原始模型正文、推理文本或凭据。

请求样例、字段和边界见[自然语言任务编译](../../development/natural-tasks.md)。

## 交付边界

READY 表示准备契约完整，`task_execution_enabled=false`；任务表单、运行调度、账号就绪、受管浏览器和执行图仍属后续子任务。业务证据验收规则已写入契约，不代表已取得网站证据或业务成功。

这版自动抽取适用于肯定、单对象、固定时期且能核对字面依据的指令；复杂否定、多对象、相对时间或未支持的表达会要求显式补参。它不声称覆盖任意自然语言。无法可靠识别未标记文本的真实作者，调用者需把网页数据放入 `web_context` 或保留显式引用标签。

真实模型端到端语义质量和供应商可用性未在本项验证；验收使用可控模型回答及真实本机 HTTP。编译失败或进程中断不代表供应商没有计费，原键不会自动重试。未知 STARTED 的自动恢复与完整本机会话安全由后续模块接入。
