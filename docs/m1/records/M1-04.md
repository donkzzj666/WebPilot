## 交付边界

READY 只表示任务契约完整，`task_execution_enabled=false`。没有自动生成带虚构配置快照的 Run，也未实现真实自然语言解析、调度、额度扣减或真实站点执行。任务 UI 在后续阶段接入。

准备阶段使用独立正整数版本游标；完整契约编号可以跳号。补参审计存入不可变准备历史，不伪造要求 run_id 的 SSE 事件。关键条件变化通过新增 `/revisions` 明确提交，有未结束运行时先返回冲突；在途动作安全停止由后续控制服务负责。
