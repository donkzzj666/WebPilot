## 发现与修复

首轮四进程同时初始化 WAL 时，部分连接立即收到 BUSY。迁移入口增加截止时间内的事务级重试，覆盖 WAL 初始化和版本竞争；普通业务事务不重放回调。随后真实多进程测试和两轮干净环境启动验证通过。较早的 `085822` 报告和 69 项组件 XML 保留为中间结果；最终验收使用上述含完整预算字段的 70 项测试版本。
