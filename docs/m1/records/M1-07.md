## 交付

- `GET /v1/settings` 和 `PUT /v1/settings/model`：配置就绪状态、当前版本、严格参数校验、数据发送确认和乐观版本比较。响应不包含密钥或 OS 凭据引用，错误不会回显输入。
- 原生 macOS Keychain 存储：固定服务名、随机 UUID v4 引用、add-only 写入、禁止交互弹窗；明确区分缺失、锁定、无权限、服务不可用和不支持的平台，无明文回退。
- 显式 v6 迁移：连续且不可变的设置版本、不可变 Run 配置绑定；参数修改或密钥轮换均不覆盖旧 Run 的快照。
- Run 创建与配置绑定、预算记录同一短事务提交；模型工厂按 Run 加载旧参数和旧凭据。历史未绑定 Run 不采用最新设置替代。
- OS 写入与 SQLite 发布分离；竞争或 SQL 失败时清理本次未被引用的新凭据，提交结果不确定时保留已被引用的 Key。
- 工作台设置区：数据接收说明和确认框、密码输入、超时和 token 参数、就绪原因、保存后清空密钥、409 冲突重载；显示本机就绪不等于供应商已验证。

接口、使用方法和失败边界见[配置与密钥开发说明](../../development/settings.md)。

## 交付边界

生产凭据后端目前只实现 macOS。设置就绪表示本机完整且凭据可读；没有付费供应商连通性验证，也不表示任务能自动执行。Worker 仍为 idle，`task_execution_enabled=false`。

后续执行图必须通过 `provider_for_run(run_id)` 创建供应商连接，不复用全局最新连接。该工厂保证旧 Run 使用原凭据；模型适配器本身的配置摘要不包含密钥值。

OS 凭据和 SQLite 不具备跨存储原子提交。进程在凭据写入后崩溃、OS 写入结果未知或补偿失败可能留下未引用凭据，当前不猜测式删除。完整凭据历史清理、调度／恢复以及本机会话令牌仍由对应后续模块接入。测试内存凭据夹具只存在于验证代码，不是生产回退方案。
