# M1-20：任务入口与配置界面

状态：**VERIFIED**。2026-10-02（北京时间）。最终新环境完整回归、真实界面验收和保护核验全部通过，M1 已完成 **21/25**。M1-21／22／24／25 保持 TODO，本次未实施。

本项复用 schema v18、自然语言编译、配置快照和身份协议，无新增迁移或依赖。界面保存任务准备，**不创建 Run、不入队、不执行外部写入，也不将 READY、配置就绪或历史身份核实展示为任务成功**。运行入口、实时进度和结果界面按后续子任务接入。

## 交付

| 能力 | 行为 |
| --- | --- |
| 自然语言入口 | 明确来源 origin、路径、起始 URL 和访问授权；默认只读；编译后显示服务实际持久契约 |
| 任务卡与重载 | 真实列表、详情、当前准备修订、允许动作、参数、输出和验收条件；URL 仅恢复非秘密任务／登录准备 ID |
| 集中补参 | 仅提交后端列出的缺失字段；补来源、写权限、账号均需明确选择或确认；不提供任意递归补丁 |
| 完整修订 | 明确目标任务；重新确认来源和权限，默认只读且清除旧账号；重新自然语言编译，不静默保留手补业务参数 |
| 409／422／未知结果 | 保留非秘密草稿；409 查询最新版本并锁定修改，核对后重新确认；422 修正再提交；同一内容在当前组件内复用幂等键 |
| 模型配置 | 后端实际支持的提供商／模型／官方地址、超时和可选静态价目；版本化保存，历史 Run 冻结快照不变 |
| 数据发送与密钥 | Key 输入之前说明正文、过滤后网页和必要截图发送给所选提供商；明确确认；密码框不回填，发送后清空，不存浏览器持久空间 |
| 账号准备 | 真实站点目录、登录准备、持久查询、版本化确认和关闭；密码／验证码在受管站点窗口输入；错账号不发布身份 |
| 公网身份边界 | 只允许 VERIFIED、public realm 且匹配全部来源的明确身份；历史记录仍须每个 Run 重新核对身份与业务条件 |
| 持久分页 | 新增 `GET /v1/tasks`，倒序插入游标为十进制字符串；有界只读快照、不建库或迁移、既有本机认证与 no-store |

修改任务目标、来源、场景、账号、写入范围或时间会撤销相关最终确认。GET 和修订／补参回执严格绑定请求的任务 ID，结构自洽的其他任务响应也被拒绝。切换任务会退出旧修订，防止查看 B 却修改 A。既有草稿的来源范围独立于尚缺的起始 URL 校验，能够继续补充匹配账号；新来源仍须完整校验和明确授权。

幂等键只在组件内存保留，重载后的新建不是原请求的幂等重试。用户应先查询服务器已有任务；已知任务与登录准备 ID 可以从 URL 重新读取。来源输入并不改变公网网络放行规则。模型配置保存不调用提供商，不能证明 Key 有效或余额充足。

## 失败历史与修复

| 问题 | 修复与证据 |
| --- | --- |
| 首轮 UI 在第 23 项后失败 | Playwright 的通用 enabled 判定跟随外层 label 到 select，未检查目标 option 本身。改为明确核对 option 的 disabled 属性与 DOM property；v2／v3 全部 29 项通过，原失败报告保留 |
| 首轮新环境启动探针等待旧占位 | 3461 项测试与前端通过，基础集成通过，启动探针等待“任务界面待接入”超时；改为实际任务入口标题，独立 14 项启动验收通过，原整体 false 保留 |
| 第二轮新环境设置页导航超时 | 前 5 组集成通过；页面 DOM complete、模型控件已就绪，但两条已返回 503 的账号元数据请求仍未结束。诊断未发现持续请求或脚本错误，原网络空闲等待仍超时 |
| 未清理失败元数据响应 | 只在账号元数据 GET 批次 finally 终止其独立 controller，清理未读响应及 Promise.all 残留请求；不改变身份变更、确认、关闭或导航判定。原探针约 0.689 秒完成导航，pending 为空，12 项检查及真实 UI 29 项通过 |

审阅期间另修复跨任务修订状态、响应对象绑定、授权变更撤销确认，以及缺起始 URL 草稿的账号匹配问题。没有跳过任何原集成检查，也没有把失败报告改记为通过；未开始后续子任务。
