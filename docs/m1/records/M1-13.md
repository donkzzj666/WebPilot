## 已实现的交付

- schema v12 显式追加观察绑定、最新页面头和不可变派发审计，继续使用既有 `observations`、`steps`、`write_intents`、预算和持久事件。SQL 触发器保护快照及步骤绑定，阻止历史替换、删除和终态覆盖；不修改 v1～v11 SQL。
- 固定 `navigate`、`click`、`input`、`keypress`、`select`、`scroll`、`switch_tab`、`read_visible`、`screenshot`、`download_attachment` 十类动作。严格解析沿用 M1-05 协议；不接受额外执行能力、任意 JavaScript、Shell、HTTP、SQL、CSS 选择器或本机路径。初始空白页的业务导航也经过网关、意图和预算。
- 语义 role／accessible_name／label、精确 DOM 属性、截图坐标按优先级供受信适配器选择，不为模型臆造退路。语义／DOM 目标必须唯一可见且可用，准备和最终派发重新核对；DOM 属性值按数据转义，不能组成任意选择器。
- 开发者固定的 DOM 观察、定位元数据和坐标命中脚本运行在 CDP isolated world。页面伪造同名主 world 对象或修改主 world 方法不能替换探针。页面版本结合导航代次、DOM／窗口／滚动／表单事件、可见文本和元素元数据；不采集密码、输入值、textarea 正文或可编辑区域正文。
- 快照绑定 Run、epoch、状态版本、会话及 manager 代次、标签、帧、页面版本与视口。坐标另绑定当前截图引用、尺寸及完整像素 SHA-256，准备和最终派发各重拍一次并各计一次截图；保持严格哈希比较。iframe 坐标采用原生内容区域几何和 `DOM.getNodeForLocation`，当前命中必须属于声明的帧，不能隔着父页面遮挡点击；不近似处理旋转／缩放的 iframe。
- 派发前重新读取 SQLite 执行资格、完整资源、控制权、冻结契约、会话、身份、权限和预算；短事务同时保存预算尝试、原子步骤 INTENT、必要写入意图及 `action_recorded` 事件。提交后才进入真实浏览器交互。同一 `step_id` 不会重新获得派发许可；失败、超时和未知结果不返还预算。
- `sequence()` 展开受信复合操作，每一步重新观察、保存审计和扣额。十次交互必须留下十次动作尝试；可见内容读取和截图分别计量。导航及只读链接打开还计内容页与同逻辑站点节奏，不能通过点击绕过至少 3 秒间隔。
- 每条浏览器请求及重定向同时受 M1-12 原网络边界、页面路由和原生 CDP Fetch 守卫约束。URL 必须匹配唯一逻辑站点及当前 Token 中对应身份／realm 的站点租约，并重查持久资格；声明第二来源或授予精确写端点不能替代第二站点的资源租约。默认只允许 GET／HEAD，受信写窗口仅开放授权的精确 `(method, url)`。
- CDP 仅回应自有受管代理的精确 Proxy 认证挑战；网站 Server 挑战、其他代理 origin、重复挑战及失效资格均拒绝。代理认证信息只在内部内存使用，无公开 RPC 或审计输出。尚未安装守卫的弹窗首次导航会阻止；受信 Worker 可创建空白受管标签，再通过网关导航和切换。
- 外部写入默认拒绝。可信页面适配器提供 repository、branch、base SHA、operation、files、identity 和精确写端点，程序与冻结仓库策略及已确认身份逐项核对。唯一内部派发窗口只允许当前已提交步骤对应的唯一 INTENT；其他意图、UNKNOWN、旧资格、RECONCILING、隔离资源和用过的步骤不能进入。
- Playwright 返回不构成业务回执。所有外部写入仍持久化为 UNKNOWN，保留站点／仓库／环境资源隔离，阻止继续自动派发和重复写入。晚到、失权或预算耗尽的结果不进入成功结果缓存；步骤完成也不将 Run 标为业务成功。
- 动作准备、写授权和派发共享本次动作的绝对截止，契约可把 30 秒上限收紧到 1～30 秒。独立截止观察器将已提交意图持久化为 UNKNOWN，撤销执行资格后再有界取消；统一 Run 预算耗尽沿调度截止路径失败。调用方取消也先撤权，不能留下仍可派发的旧协程。
- 附件必须是最新观察中的真实指定链接，Worker 内存中的 `link_evidence_id` 必须匹配 URL。下载只在显式启用的受管 Run 上下文接受，一次许可绑定页面、URL 和执行资格；未授权或第二次下载取消。读取 Playwright 生成的临时文件，默认最多 8 MiB，完成后删除，调用者不能传路径，字节仅保留于内部有界缓存。

调用顺序、开发说明和模块边界见[结构化浏览器动作网关说明](../../development/browser-gateway.md)。

## 验证问题与修正

早期清洁副本的独占诊断发现两类与业务 DOM 版本无关的原生控件像素变化：按钮圆角的单个像素变化触发最终派发前拒绝，搜索控件边缘的两个像素变化触发准备阶段拒绝。前者已保存 INTENT，因而转 UNKNOWN 并撤权；后者尚未保存动作意图，不增加动作扣数。两种情况均未重试原动作或放宽像素哈希；[首次诊断](../../../artifacts/verification/M1-13/acceptance-20260930T145607.776659Z/coordinate-raster-diagnosis/diagnosis.json)、[遮挡诊断](../../../artifacts/verification/M1-13/acceptance-20260930T145607.776659Z/overlay-raster-diagnosis/diagnosis.json)保留原始合成截图、精确调用位置及逐像素比较。

坐标案例最终移到同一已登记来源下、没有原生表单控件和滚动条的静态 parent／iframe 页面。去程和回程仍经网关导航、各计动作及内容页；观察在覆盖层绘制完成后进行。遮挡探针强制要求拒绝字段为 `locator`，并验证移除遮挡、重新观察后真实点击成功与额外两次截图计数，避免像素拒绝造成假阳性。生产源码和严格 SHA 判断保持不变。

退出后的复制工件复核还发现旧任务 API 探针引用了被导出器排除的私有 `.security` 文件。已将这些文件排除在新报告清单之外，最终全新安装及复制工件校验均通过。早期失败、诊断及[修正前工件复核](../../../artifacts/verification/M1-13/acceptance-20260930T145607.776659Z/pre-fix-evidence-check.json)保留，不覆盖为成功。

## 适用边界

本项是受信 Worker 的内部网关，不增加公开浏览器派发 API。普通模型不能取得执行 Token、页面适配器、任意脚本入口或派发许可。

持久观察正文为空、标题为固定占位，`redaction_status=BLOCKED`。Worker 中的原始可见样本、截图／链接引用及附件缓存不是已脱敏或可交付证据，不通过 HTTP 提供，也不能直接作为已脱敏模型输入。真实证据保存、过滤和受控读取属于 M1-14；成功结果聚合属于 M1-15；产品图循环属于 M1-16。

输入、按键、选择和写入按钮需要可信写适配器；只读提示不能授予表单交互权限。本项只在合成夹具验证这些动作，不声称 GitHub 真实写入、网页编辑器适配、提交／PR 回执或完整写入查证已实现。恢复、控制、写入查证按 M1-17、M1-18、M1-23 接入。

默认 Worker 仍不装配业务执行器，`task_execution_enabled=false`。本次没有重启用户既有服务、迁移默认业务库、提交或推送 Git。默认数据及历史 SQL 摘要保持不变；现有 API／Worker 需要重启后加载 schema v12 和本项代码。
