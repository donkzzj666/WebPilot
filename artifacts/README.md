# 验证产物

`verification/M1-01/` 保存历史骨架验收，`verification/M1-02/` 保存核心持久化验收。各目录保存各次检查的报告、截图、网络审计和合成测试数据库。每次检查使用新目录，失败记录也保留；报告中的 `passed`、错误描述和验收记录一起决定结果，不能只看目录日期。

这些是验证证据，不是应用代码，也不是根目录 `data/` 中的本机运行数据库。历史报告中的路径和命令反映当时的目录结构，不随重构批量替换，否则原始哈希会失效。

最终 M1-01 验收记录见 [docs/m1/records/M1-01.md](../docs/m1/records/M1-01.md)。日常检查入口仍为根目录下的 `./scripts/check.sh`。
